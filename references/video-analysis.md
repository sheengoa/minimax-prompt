# 参考视频解析规范

本文件把 MiniMax H3 提示词 skill 的生成流程反向应用于参考视频。目标不是把视频里看到的一切逐字抄进提示词，而是稳定提取"可复刻的内容、可迁移的镜头语言、需要排除的生成瑕疵"，并把解析产出直接映射到 H3 的字段与标签（`[Shot N] At MM:SS.mmm` 切镜时间、`<Subject N>` 特征清单、三线声音归属、summary 任务类型）。

## 一、适用条件与核心顺序

以下情况必须先使用本文件：

- 用户上传或提供参考视频，并要求拆解、复刻、仿拍、迁移或提取提示词。
- 用户要求只参考视频的运镜、动作、节奏、光影、转场或广告结构。
- 视频将作为 Ref2VA 的 `<Video N>` 素材上传（编辑/续拍/结构参考）。

固定顺序：

```text
视频文件
→ 基础信息与音轨
→ 关键帧和镜头边界（含切镜时间点提取）
→ 声音验证（三线预分离）
→ 画面事实
→ 主体特征与素材角色
→ 时间轴分镜（毫秒级切镜时间）
→ 全局设定与异常项
→ 生成提示词
→ 自检与不确定项
```

不要跳过"画面事实"直接写提示词。不要把"视频想表达的意思"写成"画面已经证明的事实"。

### 执行协议（统一不同会话的解析方式）

1. **确认文件**：先确认视频文件可访问；只有文件名、描述或单张缩略图时，不得声称完成了完整视频解析。
2. **读取元数据**：优先取得时长、分辨率、帧率、方向和音轨信息；无法取得的字段标记为"未确认"。**样片时长超出 4–15s 时提前标记**：复刻需拆段或压缩，见 formulas.md「长片拼接」。
3. **建立抽帧基线（缩略图墙）**：用一张拼接图覆盖全时间线，替代逐帧翻看——
   - 4–15 秒：`fps=2`（每 0.5 秒一帧），如 `ffmpeg -i 输入 -vf "fps=2,scale=216:-1,tile=8x3" 墙.jpg`。
   - 15–30 秒：`fps=1`（每 1 秒一帧）。
   - 30 秒以上：`fps=0.5`（每 2 秒一帧），必要时分段出多张墙。
   缩略图墙只负责节拍、切镜与场景结构的全覆盖；会话自带的预览帧可并入基线，不重复读取。
4. **定向补全分辨率特写**：文字、品牌字、屏幕数字、人脸、产品细节等小元素在缩略图上不可辨，按墙定位后抽取 2–4 张关键时刻的全分辨率帧查看；切镜与动作拐点可在墙的相邻格间补帧确认。禁止把整段视频逐帧抽成单张图片逐一阅读。
5. **验证声音**：按第二节「3. 音频」的验证管线取得可判定事实，判不了的字段标"未确认"；画面观察和音频判断分开记录，没有实际听清、转录或可验证文本时，不写台词原文。
6. **形成证据记录**：每个重要结论至少绑定一个时间点；涉及动作、连续性或运镜时，至少对照两个相邻时间点。**切镜点记录精确到 0.1s**（H3 正文需要 `At MM:SS.mmm` 毫秒三位，解析给出到 0.1s 的时间点，写词时补足到毫秒）。
7. **再写提示词**：完成事实层、镜头层和异常层后才开始写词。生成用途已在 SKILL.md 第 1.5 步确认，本协议各步的深度与侧重视角随用途而定。

优先使用本地视频解码和元数据工具；若当前环境只有预览、关键帧或用户截图，必须说明解析范围受限。不要为了获得视频内容绕过浏览器或文件安全限制，也不要未经用户要求把视频上传到外部服务。

## 二、解析层级

### 1. 基础信息

优先记录：

- 时长、画幅、分辨率、帧率、视频方向。
- 是否有音轨；能确认时按 **H3 三线**预分离：台词/歌声、画面内音乐、环境与动作音、观众向配乐（判定归属见 dialogue.md「三线分工」）。
- 参考视频在本次任务中的用途：完整内容、人物、产品、场景、动作、运镜、节奏、光影、转场、音色或编辑底片。

如果工具无法取得某项信息，写"未检测到"或"未确认"，不要补猜。

### 2. 关键帧与镜头边界

抽帧节奏与命令按「一、执行协议」第 3 条的缩略图墙执行，此处只定证据规则：

- 无论时长，必须单独核对首帧、尾帧、所有明显切镜点和最终定格/收束画面。
- 抽帧是为了建立时间证据，不是为了替代连续动作观察：墙上看不出的连续运动（是镜头推近还是主体靠近、快慢变化），回原视频或补相邻帧确认。

镜头边界优先依据：

1. 画面直接切换或明显淡入淡出、叠化、遮罩。
2. 日夜、地点、布光、背景空间发生明确变化。
3. 主体动作从准备转为执行、从执行转为完成。
4. 产品从环境展示转为细节展示，或景别明显改变。

**每个切镜点记录时间（精确到 0.1s）+ 新信息类型**（主体/空间/状态/视角/时间）——这决定 H3 正文里这个切镜是否值得保留：不引入新信息的切镜在写词时改为运镜句。

只在能从画面证据支持时写"推近、拉远、跟拍、摇镜"等运镜。人物靠近镜头不等于镜头推近；背景透视、主体相对画幅大小和机位稳定性不足以确认时，写"主体靠近镜头，镜头运动未确认"。确认的运镜直接映射官方三维表（类型+幅度+速度，见 vocabulary.md）。

### 3. 音频

**验证管线**（三条命令串成一次调用跑完，再读一张频谱图）：

```bash
ffprobe -v error -select_streams a -show_streams 输入   # ① 音轨是否存在、声道与采样率
ffmpeg -i 输入 -af silencedetect=noise=-30dB:d=0.5,volumedetect -f null -   # ② 静音段与响度 → 声音分布时间线
ffmpeg -i 输入 -lavfi "showspectrumpic=s=1200x480:legend=1" 频谱.png        # ③ 频谱图，读图判断声音结构
```

频谱图可判定的事实：持续水平谐波带 = BGM 或人声存在；垂直宽带脉冲 = 动作音效（拉链、碰撞、脚步）；等间距竖栅 = 节拍与节奏密度；仅低频隆起 = 底噪/环境音。**频谱还原不了台词与歌词**——环境装有 whisper 等转写工具时先转写再引用原文，否则台词一律标"未确认"。

判定写法分两档：

- **可判定**：`有 BGM，中速明快`、`无 BGM，仅环境音`、`2.0–2.4s 有一次宽带脉冲（疑似拉链/撕开声，置信度中）`。
- **未确认**：`音轨存在，BGM 与人声难以区分`、`台词内容未确认`——写进解析报告与假设说明，不得在提示词里冒充已确认事实。

在此之上按 H3 三线归类记录：

- 台词/歌声 → 将进主描述字段（`<d>` 标签，说话人 + ID）。
- 画面内音乐（radio/电视/手机/现场演奏，角色能听到）→ 将进主描述字段（画面内事件）。
- 环境音与动作音效 → 将进 `overall_soundscape`。
- 观众向配乐 → 将进 `non_diegetic_music`（记乐器、速度、强弱变化，不记情绪词）。

没有实际听清或完成转录时，不能编造台词和音乐类型。可以写"有音轨，但对白未确认"。

### 4. 文字与水印

- 清晰可读的文字才逐字记录（H3 正文里放英文双引号内，保留原文）。
- 模糊的屏幕数字、品牌名或包装字样写"疑似某内容，不可确认"。
- 平台水印、AI 生成标识、乱码和随机字幕，单独列为"叠加层/异常项"，默认不进入正向提示词。
- 要求复刻品牌或标签时，优先使用参考图锚定（`<Picture N>` + `<Subject N>` 定义特征），不要依赖模型凭空生成长文字。

## 三、事实、意图和异常必须分开

每个重要结论使用以下标签之一：

- `【画面事实】`：能在一个或多个时间点直接看到或听到。
- `【镜头结构】`：由时间顺序和画面变化归纳出的景别、构图、运镜、转场或动作链。
- `【叙事/广告意图】`：对视频作用的解释，例如"用日夜变化表达经过一夜"。
- `【待确认】`：清晰度、音频或时间证据不足。
- `【疑似生成瑕疵】`：物理、连续性、文字或身份变化不合理，但不能确定是创作者有意设计。

置信度使用以下固定等级：

- **高**：来自元数据，或在清晰画面/音频中直接可见可闻；动作和运镜有相邻时间点支持。
- **中**：多个时间点支持，但存在遮挡、分辨率不足、运动模糊或镜头边界不确定。
- **低**：主要来自叙事逻辑、广告语义或单帧推断；必须同时标为"待确认"或"叙事/广告意图"。

最低证据要求：

- 产品名称、品牌、型号、屏幕数字和具体功能：必须有清晰局部画面或用户说明。
- 台词原文：必须能听清或有字幕/文本依据。
- 镜头运动：必须结合连续帧判断，不能只凭单张图。
- "烘干完成""变干""变热"等功能结论：除非视频给出明确证据，否则写成广告意图或"视频试图表达"。

## 四、固定拆解输出

字段与顺序固定，**深度随用途裁剪**（衔接 SKILL.md 第 1.5 步）：样片复刻与仅解析学习交付全字段；迁移类只精读并保留要迁移的层，其余字段可一行带过；编辑只需锁定底片相关区间。本次裁剪了哪些字段，写进报告末尾的"假设与待确认"。

每条参考视频的解析报告按以下顺序输出：

```text
【参考层与边界】（即"参考什么"，注意不是 SKILL.md 第 1.5 步的"素材角色"）
视频1：完整内容 / 只参考运镜 / 只参考动作 / 只参考节奏 / 只参考光影 / 场景参考 / 编辑底片
参考：……
不参考：……

【视频基础信息】
时长（是否超 15s）：
画幅与分辨率：
帧率：
音轨：

【一句话事实摘要】
用主体 + 场景 + 主要事件 + 风格表象描述，不加入未经证实的功能结论。

【主体特征清单】（→ <Subject N> 定义与 retention 标记）
主体1（人物/产品/场景）：要跟随的特征逐项列出——外观、服装、材质、颜色、姿态
主体2：……
风格与光影锚点：……

【时间轴分镜】（→ [Shot N] At MM:SS.mmm）
每个时间段都填写：
切镜时间点｜主题词
画面事实：
景别与构图：
运镜（类型+幅度+速度）：
动作链：
光线与色调：
材质与物理细节：
台词/歌声（说话人+原文/未确认）：
环境与动作音：
配乐（乐器/速度/强弱）：
转场与新信息类型：
镜头意图：
置信度/异常：

【全局设定提炼】
风格与构图开场（→ [Shot 1] 前或句首的风格句）：
环境与质感：
镜头语言：
主体一致性：

【异常项与排除】
原片水印、乱码、随机字幕、疑似生成瑕疵：
写词时需在正文排除短语中点名的项：

【生成用途】（→ summary 任务类型前缀）
与 SKILL.md 第 1.5 步的确认一致：样片复刻（T2VA/Ref2VA 重写）/ 参考生成 / 视频编辑 / 视频续拍 / 音频复用 / 仅解析

【假设与待确认】
……
```

多段视频必须先固定上传编号映射（第 1 段 = `<Video 1>`、第 1 张图 = `<Picture 1>`、第 1 段音频 = `<Audio 1>`，与上传顺序严格一致），再逐条使用以上格式。

批量视频的处理顺序固定为：

1. 先建立完整的上传编号与用途映射。
2. 每条视频独立完成基础信息、事实层和时间轴，不提前把不同视频的内容混在一起。
3. 所有单条视频完成后，再输出跨视频共性：共同运镜、共同节奏、共同光影或共同广告结构。
4. 生成提示词中只引用用户指定用途的素材；用途未指定时先按 SKILL.md 第 1.5 步确认，无法确认时按"只迁移镜头/动作/节奏，不迁移主体内容"的保守原则处理，并在假设说明中写明。

如果用户只说"参考这个视频"而没有说明参考层：

- 有明确新产品、新人物或新场景时，默认按"迁移镜头语言与广告结构"处理（`reference generation`），原视频主体不作为生成主体。
- 没有替换对象且要求"复刻/仿拍"时，按"完整内容参考"处理。
- 两种解释都会影响结果时，先给出用途判断并只追问一个关键问题，不要静默选择。

## 五、时间轴字段的写法

### 景别、构图、运镜

每个时间片至少写全：

```text
景别 + 机位/视角 + 构图 + 一个主要运镜
```

例如：

```text
低机位中景，产品位于前景中央，人物位于背景右侧，固定机位。
```

不要在同一时间片堆叠互相冲突的指令，例如"固定机位同时缓慢推近并环绕"。

### 动作链

按"先 → 再 → 最后"写可观察的物理过程：

```text
先走近设备，再蹲下扶住鞋身，最后把鞋口套到支架上。
```

不要只写"完成烘干""展示效果""显得很高级"。写词时动作链转成英文自然句，每镜只保留一个主动作。

### 光影、材质和情绪

- 光影写光位、色温和反射，例如"暖黄色落地灯 + 设备冷蓝光 + 木地板局部反光"。
- 材质写可见物理证据，例如"帆布鞋面纤维、塑料外壳高光、液滴沿鞋底滴落"。
- 情绪写外化动作，例如"打哈欠、眼睑下垂、肩膀放松"，不要只写"疲惫"。

## 六、从解析结果映射回提示词

按解析用途选择公式（生成公式详见 formulas.md）：

### 样片复刻（视频不上传）

全篇零 `<Video N>` 引用——把解析结果按 SKILL.md「样片复刻公式」重写为自包含提示词：切镜时间照搬为 `At MM:SS.mmm`，主体特征清单改写为绝对描述，台词进 `<d>`，三线声音各归其位。带新参考图时走 Ref2VA（`[reference generation]`），纯文字重写走 T2VA。

### 素材引用（视频上传，`<Video N>`）

- **编辑**：summary `[video editing + …]`，`detailed_description` 描述编辑后的成片；多处局部编辑逐条列出、每处与保持约束成对写（formulas.md「编辑任务」），互相影响的大改才拆分任务。
- **续拍**：summary `[video continuation + …]`，前部承接源片结尾状态再展开。
- **迁移运镜/动作/节奏**：`<Video 1> (cut and pacing structure): weak_reference`；正文只在结构层面引用，主体内容用新描述。
- **音色/配乐**：建 `<Audio N>`，按 dialogue.md 写明复制还是参考。

### 仅解析学习

交付本文件固定模板的完整报告即止，不写提示词。

参考视频分析报告不是最终提示词，它是写词前的证据层。最终交付按 SKILL.md 第 4 步执行（解析报告、正文、中文对照、平台设置、素材清单/改动核对单、可调项、假设说明），并通过第 5 步自检。

## 七、解析后的自检

- [ ] 时长、画幅、切镜时间来自视频证据或明确标为未确认。
- [ ] 每个时间片都有一个主动作和一个主要运镜；切镜点都标注了新信息类型。
- [ ] 每个镜头的景别、机位、构图和动作互相匹配。
- [ ] 画面事实、叙事意图、待确认项和疑似瑕疵没有混写。
- [ ] 没有把水印、乱码、随机字幕或物理错误自动写入正向提示词。
- [ ] 没有编造品牌、型号、屏幕数字、台词、音乐类型或人物背景。
- [ ] 主体特征清单完整到可直接支撑 `<Subject N>` 定义与 retention 标记。
- [ ] 声音已按 H3 三线归类；未确认的声音设计已写入假设说明。
- [ ] 样片复刻场景：预告正文将全篇零 `<Video N>` 引用、零"与原片"式对比（与 SKILL.md 自检一致）。
- [ ] 生成稿仍通过 SKILL.md 的时长、素材上限、切镜时间、字段结构与台词格式检查。
