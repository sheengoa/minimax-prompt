# minimax-prompt

**MiniMax H3 视频提示词工程 Skill** —— 把「我想要一条什么样的片子」翻译成 H3 能准确执行的结构化提示词。

依据 MiniMax 官方《Video Prompt Writing Guide》（T2VA / I2VA / FL2VA / L2VA）、《Full-Reference Mode Rewrite Output Format Guide》（Ref2VA）与平台文档提炼，原文存档于 [`docs/`](docs/)。产出可直接粘贴到海螺 AI（hailuoai.com / hailuoai.video）、MiniMax Hub（hub.minimax.io）或 API `content` 字段使用。

```
用户需求 ─▶ 本 skill（访谈 · 路由 · 写词 · 自检）─▶ 可直接粘贴的 H3 提示词 + 中文对照 + 平台设置 + 素材清单
```

## 为什么需要它

H3 的提示词不是「一段描述」，而是一份**有固定字段名的结构化说明书**：

- 正文必须用**英文**写，只有台词、歌词、画面可见文字保留原语言；
- 叙事单位是 `[Shot N]` + **毫秒级切镜时间**（`At 00:03.500`），不是段落；
- 台词是指令：说话人 `(S1)` + `<d>[English] …</d>`，逐字逐标点；
- 一致性靠 `<Subject N>` / `<Picture N>` / `<Video N>` / `<Audio N>` 引用标签，不是反复形容；
- 声音必须**三线分离**，串线就出事故。

凭直觉写，通常得到的是「意思到了、模型没接住」。这个 skill 把这些约束固化成了可复用的流程、公式与检查清单。

## 核心能力

| 能力 | 具体做法 |
|---|---|
| **结构化字段** | 基础模式三字段式、全参考模式六段式，字段名 / 顺序 / 标签严格照官方，不自创 |
| **毫秒级时间轴** | `[Shot 1]` 无时间戳，其后每镜 `At MM:SS.mmm` 严格递增且落在时长内 |
| **台词即指令** | 说话人稳定 ID `(S1)`、`<d>[语言] 原话</d>`、旁白 / 跨镜 / 被截断台词各有官方句式 |
| **四类引用标签** | `<Subject>` 内容单元、`<Picture>` 帧锚、`<Video>` 整片关系、`<Audio>` 音频信号，配 `retention_analysis` 保真标记 |
| **声音三线分离** | 台词歌声进主描述、环境动作音进 `overall_soundscape`、观众向配乐进 `non_diegetic_music` |
| **素材角色分流** | 上传视频先回答「生成时传不传给模型」，据此分四路，避免写出一条引用不存在素材的提示词 |
| **参考视频解析** | 缩略图墙覆盖全时间线 + 全分辨率关键帧补证，切镜点精确到 0.1s，画面事实与推断分层记录 |
| **失败诊断** | 14 条症状 → 修改策略速查，配「一次只改一个变量」的归因纪律 |

## 工作流

```
用户需求
  │
  ├─[0] 选变体 ─── MiniMax-H3（全模式）/ H3-Max（纯文生·图生求快）── 拿不准默认 H3
  │
  ├─[1] 路由 ───── T2VA｜I2VA｜FL2VA｜L2VA｜Ref2VA｜样片复刻｜长片拼接
  │
  ├─[1.5] 素材角色 ─ 上传了视频/图片？先判断「生成时会不会传给模型」
  │      ├─ A 样片复刻（不传）→ 全片逐镜解析 → 自包含 T2VA，零引用样片
  │      ├─ B 素材引用（传）  → Ref2VA 标签体系
  │      ├─ C 编辑（传）      → [video editing] 任务类型
  │      └─ D 仅解析          → 只出解析报告，不写提示词
  │
  ├─[2] 需求访谈 ── 8 维清单（主体/风格/镜头/台词/声音/时长/画幅/素材），只问缺失且关键者，一次≤3 问
  │
  ├─[2.5] 方向对齐 ─ 需求笼统时给 2–3 个拉开差距的方向卡，选定后直接写
  │
  ├─[3] 写词 ───── 官方字段结构 + 英文正文 + 三线声音 + 运镜三维表
  │
  ├─[4] 交付 ───── 正文 + 中文对照 + 平台设置 + 素材清单 + 可调项 + 假设说明
  │
  ├─[5] 自检 ───── 字段/时间轴/标签/声音/边界 12 项清单
  │
  └─[6] 失败诊断 ─ 不满意 → 14 条症状速查；小瑕疵用指令编辑修，不整条重跑
```

### 各步要点

| 步 | 关键判断 | 产出 |
|---|---|---|
| **0 选变体** | 要参考生成 / 首尾帧 → 只有 H3；纯文生图生求快 → H3-Max 可用 | 模型 + 分辨率 + 时长上限确定 |
| **1 路由** | 命中具体功能（编辑/续拍/首尾帧/台词/复刻）优先于通用公式 | 模式与公式文件定位 |
| **1.5 素材角色** | 每个引用标签都必须对应一个真实上传的素材 | 素材处置结论（上传 / 不上传） |
| **2 访谈** | 有默认值的用默认值并注明假设；主体无默认，必确认 | 8 维需求表 |
| **2.5 方向对齐** | 仅需求笼统或「主体 + 风格」两维皆空时触发 | 2–3 个创意方向 |
| **3 写词** | 一镜一个主动作、一个运镜；切镜必须引入新信息 | 英文正文 |
| **4 交付** | 固定「1 份正文 + 5 项附件」 | 可粘贴整套材料 |
| **5 自检** | 结构 → 时间 → 标签 → 声音 → 边界，逐项过 | 通过 / 返工 |
| **6 诊断** | 先查参数与标签，再改措辞；一次只改一个变量 | 下一版提示词 |

## 提示词长什么样

**基础模式（T2VA / I2VA / FL2VA / L2VA）——三字段式**

```text
integrated_multimodal_description: [Shot 1] Cinematic, live-action, a medium-wide shot frames…
[Shot 2] At 00:03.500, the camera cuts to…
overall_soundscape: …
non_diegetic_music: …
```

**全参考模式（Ref2VA）——六段式**

```text
subject_definitions    参考内容与标签定义
summary                方括号任务类型 + 目标视频概括
retention_analysis     逐标签保真程度
detailed_description   按播放顺序逐镜描述
overall_soundscape     全片环境音与物理音
non_diegetic_music     仅观众可闻的配乐
```

> 基础模式 I2VA / FL2VA / L2VA 需在字段前加官方**首行指令句**（精确句式，不可改写），指令行后空一行再进字段。

## 交付物

每次产出固定为「1 份正文 + 5 项附件」，不需要再追问怎么用：

1. **提示词正文** —— 代码块，英文，按官方字段结构，可直接粘贴
2. **中文对照** —— 逐段说明正文写了什么，台词给出原话
3. **平台设置** —— 一行照抄：`MiniMax-H3｜Ref2VA｜8s｜9:16｜768P`
4. **素材清单** —— 按上传顺序列出，标明「第 1 张图 = `<Picture 1>`」；复刻场景附**改动核对单**，一条改动对一句正文
5. **可调项** —— 2–4 处：想换风格 / 节奏 / 台词，改哪一句
6. **假设说明** —— 用了哪些默认值，一句话交代

## 安装

源文件维护在本仓库，以链接方式接入 agent 的 skill 目录（便于 `git pull` 后即时生效）。

**Windows（Junction）**

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\.agents\skills\minimax-prompt" -Target "D:\code\minimax-prompt"
# 若使用 ZCode 等兼容目录：
New-Item -ItemType Junction -Path "$env:USERPROFILE\.zcode\skills\minimax-prompt" -Target "D:\code\minimax-prompt"
```

**macOS / Linux（symlink）**

```bash
ln -s /path/to/minimax-prompt ~/.agents/skills/minimax-prompt
```

安装后，agent 读到 `SKILL.md` 的 frontmatter 即可在相关请求上自动加载。

## 怎么触发

直接把需求说清楚即可，例如：

- 「用 H3 写一条 8 秒的产品广告，白色背景，最后出标语」
- 「这张图当首帧，人物走进雨里，10 秒，竖屏」
- 「拆解这条参考视频，给我一份能复刻的分镜提示词」（附视频）
- 「这条片子人物换成短发的男性，其他照旧复制」
- 「把这段口播做成数字人，音色用我给的音频样本」
- 「上一条视频接着拍，5 秒，情绪更沉一点」

不确定参数也没关系——skill 会按 8 维清单只问缺失的关键项，其余用默认值并在交付时注明假设。

## 参数硬边界

| 项目 | MiniMax-H3 | MiniMax-H3-Max |
|---|---|---|
| 单次时长 | 4–15s（仅整数） | 5–15s（仅整数） |
| 分辨率 | 768P / 2K（2K 走重生成） | 480P / 768P |
| 功能模式 | T2VA / I2VA / FL2VA / L2VA / Ref2VA | 仅 T2VA / I2VA |
| 参考图片 | ≤9 张 | — |
| 参考视频 | ≤3 段，每段 2–15s，总 ≤15s | — |
| 参考音频 | ≤3 段，每段 2–15s，总 ≤15s | — |
| 混合素材 | ≤12 个文件 | — |
| 提示词长度 | ≤7000 字符 | 同左 |
| 通用规格 | 24 FPS；32 kHz 立体声原生音频 | 同左 |
| 台词稳定语种 | 中英日韩法德意西葡俄阿（11 种） | 同左 |

## 生成不满意？先看这几条

| 症状 | 修改方向 |
|---|---|
| 切镜没按时间执行 / 镜数不对 | 核对 `At MM:SS.mmm` 递增无跳跃、落在时长内；每镜只留一个主要事件 |
| 台词没说出来 / 说了没写的话 | 核对 `<d>` 格式与语言标签；首次出现补身份描述；按每秒约 2 词核对容量 |
| 参考图人物不像 | `subject_definitions` 补足特征清单；首次出现处重述参考特征；核对上传顺序 = 标签编号 |
| 配乐混进环境音 / 环境音里有台词 | 字段串味，重分三线 |
| 运镜乱 / 画面晃 | 一镜一个运镜句，补 `at slow speed` / `with small amplitude`；无意义运动改 `Static Shot` |
| 结尾仓促 / 时长被截断 | 内容量减 20%；结尾动作链收束写短 |

完整 14 条见 [`SKILL.md`](SKILL.md) 第 6 步。

## 它不做什么

- **只产出 MiniMax H3 提示词**——H3 的字段结构自成体系，不套用通用文案模板；
- **不接入 API、不算成本**——只解决「提示词怎么写」；
- **不承诺 1:1 复制**——样片复刻是结构级复刻：同节拍、同风格、同镜头逻辑的新片子；
- **不编造未经验证的口径**——官方指南与实测都未覆盖的领域明确留白（见 `references/model-notes.md`「预期管理与留白」）。

## 来源与维护

- **权威基准**：`docs/` 中的两份官方指南原文是字段结构、指令句式、标签规则的唯一权威；与本 skill 冲突时以原文为准。
- **更新触发**：H3 模型迭代后同步修订参数边界（时长、素材上限、分辨率档）与公式；模型能力画像变化时更新写词策略。
- **收录边界**：只保留影响提示词写法的信息（字段结构、写法规则、参数边界）；计费、API 集成等与写词无关的内容不入库。
- **能力画像**：强项为指令式编辑、文字与视觉包装、参考一致性、口型同步；弱项为高张力影视镜头、极小画面文字、复杂人群调度——写词时主动绕开，并提前对齐预期。
